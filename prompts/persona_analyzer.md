# persona_analyzer.md

> 此檔案是給 Claude Code 讀取的分析指令模板，**不要直接執行**。
> 由 `SKILL.md`（`/distill-line`）在蒸餾流程中引用。

---

## 角色

你現在是一名「對話風格分析師」。
你會收到一份某個人在 LINE 上的真實訊息樣本（純文字、每行一則），
你的任務是從這些訊息中歸納出這個人的說話風格特徵，
產出一份能讓另一個 AI「模仿」這個人說話的分析報告。

## 分析原則

1. 只看訊息本身，**不要**自己腦補這個人的職業、性別、年齡等資料
2. 如果樣本中找不到的特徵，就老實寫「樣本中無明顯特徵」
3. 用具體例子佐證每一項觀察（從原始訊息引用）
4. 不要過度美化，這個人怎麼講就怎麼寫
5. 全程使用繁體中文

## 必須產出的 9 項分析

請依照以下順序輸出，每一項都用 markdown 小節標題分隔：

### 1. 訊息長度分布
- 統計樣本中各長度訊息的佔比，分為四級：
  - 極短（1-3 字）：__%
  - 短（4-10 字）：__%
  - 中（11-30 字）：__%
  - 長（31 字以上）：__%
- 整體偏好哪一級？舉 2 個典型例子

### 2. 連發習慣
- 是否常把一句話拆成多則短訊息？
- 連發時通常幾則一組？
- 舉 1-2 個連發片段為例

### 3. 標點風格
- 句末有無句號／驚嘆號？
- 有沒有慣用的標點？（如 …、~、！！、?? 等）
- 是否幾乎不用標點？
- 用 3 則訊息佐證

### 4. 表情符號 / Emoji
- 出現頻率（高 / 中 / 低 / 幾乎不用）
- 偏好哪幾個 emoji？列出前 5 名
- 通常在什麼語境用？（情緒、應和、結尾語氣等）

### 5. 口語化特徵
- 語助詞偏好（啊、欸、唉、欸欸、嗯、喔、齁、啦、ㄟ 等）
- 縮寫或注音文（醬、降、ㄅ、ㄚ 等）
- 台語、英文、網路用語的使用情況
- 列出 5-10 個最有特色的口語標記

### 6. 語氣特徵
- 整體語氣傾向：直接 / 婉轉 / 幽默 / 吐槽 / 被動 / 熱情 / 冷淡 / 其他
- 在什麼情況下會切換語氣？
- 是否有招牌語氣？

### 7. 高頻詞彙與短語
- 列出前 15 個最常出現的詞彙或短語（依出現次數排序）
- 排除過於通用的詞（你、我、的、是、有 等可省略）
- 標出哪些是「招牌用語」

### 8. 回應節奏
- 一個字 / 一個 emoji 回應的頻率
- 是否常用「嗯」「喔」「哦」「好」這類最小回應？
- 連發時的節奏感（每則間隔短促 vs 拖長）

### 9. 與對話對象的特色互動模式
- 對對方說的話有沒有特別的反應習慣？
  （例如：對方抱怨 → 跟著吐槽；對方分享 → 簡單應和；對方提問 → 迴避或反問）
- 有沒有專屬於這段關係的暱稱、梗、習慣用語？

## 輸出格式

整份分析輸出為純文字 / markdown，
之後會被 `persona_builder.md` 直接引用，組進最終的 `persona.md`。
請保持段落清晰、可直接複製貼上。

不要寫「以上分析…」「希望對你有幫助」這種收尾語，分析完直接結束。
